# airportlink-ticket-machine
## About the Project
This is a Java project that simulates an Airport Rail Link ticket machine. Users can select stations, buy tickets, create cards, and top up their card balance.

This project was developed as part of a university course.

## Features
- Display available train stations
- Select starting and destination stations
- Calculate ticket fares
- Choose card types (Normal, Senior, and Student)
- Calculate ticket discounts
- Process payments and calculate change
- Create customer cards
- Top up card balance
- Display travel routes and estimated travel times

## Technologies Used
- Java
- Eclipse IDE

## OOP Concepts
- Classes and Objects
- Encapsulation
- Constructors
- Methods

## Project Type
Java Application
